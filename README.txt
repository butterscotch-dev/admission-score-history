今回の変更（2026-10-09）:
- 二次一括入力（%）を共テ一括入力と同様に、通常二次科目の各入力欄へ実点として見える形で反映。
  例：数学200点満点・60% → 数学欄120点。
- 一括入力した科目は、年度ごとに過去問の素点満点が異なっても、表示中の全年度で指定した得点率（例：60%）を維持して換算。
- 一括入力後に個別科目を手入力すると、その科目だけ一括管理から外れ、入力した素点を優先。
- 一括管理中の科目は「採点に使った満点」を変更すると表示中の実点も同じ得点率を保って追従。
- 「その他」・面接・小論文などの専用項目は従来どおり二次一括入力の対象外。
- 阪大外国語学部の二次英語は専用入力のまま分離し、一括入力にも対応。
